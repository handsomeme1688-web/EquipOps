# EquipOps

基于某大型上市电子制造企业TPM 设备管理系统改造的智能设备运维平台

## 已完成

- JWT 身份认证
- 用户、角色与权限关系
- 部门级数据隔离
- 设备管理
- Redis 设备详情缓存
- 工单创建与并发接单
- 工单状态流转
- 文件上传

## 开发中

- AI 智能助手
- 前后端工单完整联调
- 操作审计完善
