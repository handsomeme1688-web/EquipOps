# EquipOps

基于某大型上市电子制造企业TPM 设备管理系统改造的智能设备运维平台

## 已完成

- JWT 身份认证
- 用户、角色与权限关系
- 部门级数据隔离
- 设备管理
- Redis 设备详情缓存
- 工单创建与并发接单
- 工单状态流转
- 文件上传

## 开发中

- AI 智能助手
- 前后端工单完整联调
- 操作审计完善

## 前端 Mock 展示

以下页面或数据目前主要用于预览：

- 部分监控数据
- AI 页面
- 尚未接通的管理页面

前端支持 Preview 模式，不能将所有页面都描述为已接入真实后端。

## 当前实现边界

- Spring Security 已接入 JWT 身份认证和方法级权限校验；部门数据隔离与工单业务规则仍由 Service 层强制保证
- 工单幂等键由客户端传入，数据库唯一约束兜底；暂未做独立的分布式幂等缓存
- 操作日志已具备 traceId、独立事务和失败隔离，审计查询与异步化仍在完善
